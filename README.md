# meisho-scanner（名証コンテスト用 夜の好材料スキャナー）

名証の学生向け株式投資コンテストのために、**引け後（15:30以降）に出た名証上場銘柄の適時開示**を集めて分類し、スマホで見られる1ページにまとめるツールです。売買やコンテストサイトへのログインは一切しません。

- 仕様：[SPEC.md](SPEC.md)
- 公開ページ：GitHub Pages を設定すると `https://<ユーザー名>.github.io/meisho-scanner/` で見られます

## 自動実行
GitHub Actions（GitHubのサーバーで決まった時刻にプログラムを動かす仕組み）で、取引所の営業日の日本時間 **16:10・17:10・18:40・20:40・22:40** に実行します。
- 祝日・年末年始は実行しません。土日は最初から予定に入れていません。
- GitHubの都合で、数分〜数十分遅れることがあります。
- すぐに実行したいときは、GitHub の **Actions** タブ →「scan」→「Run workflow」を押します（手動実行）。

## ページの見方
上から順に並んでいます。
1. **締切**：今夜の注文締切（翌営業日の朝7:59）
2. **取得できなかったもの**：データが取れなかったときに表示します（前回のデータを使っている場合もあります）
3. **TOBの大きな枠**：TOB・MBOの対象になった銘柄が出たときだけ表示します
4. **S → A → 要確認 → 参考 → 悪材料** の順に並べた候補
5. 15:30より前の開示（参考）、TOBトラッカー

各候補には、コード・会社名・名証単独か重複か・開示時刻・タイトル・開示PDFボタン・本日終値（＝今夜の約定見込み価格）・300万円で買える株数・株探リンクを表示します。

## TOB価格の書き込み（tob_prices.csv）
PDFは自動で読まないため、TOB価格はあなたが書き込みます。ページの「TOB価格を書き込む」ボタンから編集画面を開き、1行に「コード,TOB価格,メモ」を書いて保存（Commit changes）してください。

```
code,tob_price,memo
1439,2150,安江工務店
```

次回の実行から「TOB価格と終値の差（%）」を計算します。差が1%以下になると「売り時」と表示します。

## データの出どころ
| データ | 取得元 | 備考 |
|---|---|---|
| 適時開示の一覧 | やのしんWEB-API（TDnetの一覧を配信する非公式API） | TDnet本体は robots.txt で自動取得を拒否しているので、**PDF/XBRLは自動で読みません** |
| 名証の上場銘柄・単独/重複・売買単位 | 名証公式サイトの上場会社検索 | 1日1回取得 |
| 終値・最終気配 | 名証公式サイトの「日報」「株式相場表（速報）」PDF | コンテストの約定価格（名証の終値・最終気配）に対応 |
| 予備の株価 | Yahoo Finance（yfinance） | 名証の相場表が取れないときだけ。東証にも上場している銘柄のみ |

アクセスは1回の実行で数回〜十数回にとどめ、間隔をあけて、結果は `data/cache/` に保存しています。

## 手元で動かす場合（開発者向け）
```bash
pip install -r requirements.txt
python -m scanner          # docs/index.html ができる
python -m pytest -q        # テスト
```
